# 🎮 元素决战 - 回合制卡牌对战游戏

一款基于Web的回合制卡牌对战游戏，包含丰富的卡片系统、黑市商店和PVE冒险模式。

## 🎯 游戏特色

- **5种卡片品质**：白色、绿色、紫色、金色、红色
- **3种卡片类型**：战斗技能、附加技能、英雄卡片
- **黑市商店**：每日刷新5张随机卡片，首次特价100元
- **回合制战斗**：圣光降临投掷1-6技能点，策略性释放技能
- **PVE冒险**：5个关卡，3个Boss，击杀Boss有概率掉落稀有卡片
- **状态效果**：灼烧、冻结、中毒、眩晕、护盾、吸血等

## 🎮 游戏玩法

1. **初始资金**：500金币
2. **黑市商店**：购买不同品质的卡片
3. **卡牌背包**：选择出战英雄（最多1张）和战斗技能卡组（最多6张）
4. **PVE冒险**：挑战关卡获取经验和金币
5. **战斗系统**：
   - 每回合投掷技能点（1-6点）
   - 消耗技能点释放对应卡片
   - 可选择重置模式或累积模式

## 🚀 快速开始

1. 克隆仓库
```bash
git clone https://github.com/你的用户名/Elemental-Showdown.git
```

2. 打开游戏
```bash
# 直接在浏览器中打开 index.html
# 或者使用本地服务器
npx serve .
```

3. 开始游戏！
